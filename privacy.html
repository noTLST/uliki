Uliki Clip Uploader

Privacy Policy

Last updated: 23 November 2026

1. Use of YouTube API Services

Uliki Clip Uploader ("the tool") uses YouTube API Services to upload videos to YouTube channels owned by the person who runs the tool. By using the tool you are also agreeing to be bound by the YouTube Terms of Service. Google's handling of your information is described in the Google Privacy Policy.

2. What information the tool accesses

When the channel owner signs in with Google and grants permission, the tool receives:

  • an OAuth access token and refresh token for the connected channel, with the scopes needed to upload videos, set thumbnails and add captions;
  • the identifier and title of the connected channel (to show which channel was connected);
  • the identifiers and processing status of videos that the tool itself uploaded.

The tool does not access watch history, subscriptions, comments, analytics, or data about any other channel or user.

3. How the information is used and stored

  • Tokens are stored only on the owner's own computer, one file per channel, and are used only to upload the owner's videos to the owner's channel.
  • Channel and video identifiers are kept in a local database on the same computer so that the tool knows what has already been uploaded.
  • No YouTube data is sent to any server other than Google's, sold, shared with third parties, or used for advertising.
  • The tool does not use cookies and does not place or read information on any other person's device.

4. Retention and deletion

Stored data is deleted when the owner disconnects a channel: the token file and the local records for that channel are removed. Authorization data that has not been refreshed is not kept longer than 30 days.

You can revoke the tool's access to your Google account at any time on the Google security settings page. After access is revoked the tool can no longer upload to the channel, and the stored token is deleted.

To request deletion of any data, use the contact below; the request is completed within 7 days.
